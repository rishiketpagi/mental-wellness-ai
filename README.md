# Mental Wellness AI

Calm, supportive wellness app with mood tracking, journaling, and guided insights.

Live URL: https://calmora-livid.vercel.app

## Features

- Mood check-ins with history, edit, and delete
- Journal reflections with AI analysis, edit, and delete
- Firebase Auth and Firestore persistence
- Mobile-first, gentle UI

## Tech Stack

- React + Vite
- Tailwind CSS
- Firebase Auth + Firestore
- Express backend
- Gemini API
